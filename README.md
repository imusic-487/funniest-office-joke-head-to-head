## What it does

`main.py` writes a single one-line joke about office life to `/output/entry.txt`:

> I declined the meeting, so Outlook invited me to a meeting about why I declined the meeting.

Setup: declining a meeting. Turn: the system answers the defiance with a
meeting *about* the decline. Punchline last, 92 characters, one line.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

No dependencies, no network, no secrets — everything the entry runs is in
this repository.
